ROUTE CALCULATION

How route calculation works

See how the route calculation works behind the scenes.

01

Build the graph

Places become nodes and routes become weighted edges containing distance, travel time and cost.

02

Calculate f(n)

f(n) = g(n) + h(n)
g(n) is the cost travelled so far; h(n) estimates the remaining cost.

03

Select the best node

A priority queue expands the most promising node until the destination is reached.

04

Generate the plan

The final path is reconstructed and converted into distance, time, cost and a day-wise itinerary.

Three optimization choices

Shortest DistanceMinimizes total kilometres
Fastest RouteMinimizes total travel time
Cheapest RouteMinimizes total travel cost
